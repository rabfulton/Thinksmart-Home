# Radio module

Delegate radio requests to the backend with <|SpawnThinking|>. It can choose curated favourites or search worldwide stations by country, language or genre. For broad requests such as play some music, have it choose and play a music station without asking for a genre. Wait for actual results; never require the user to find BBC Radio 4 or the parliamentary stations in a list.

Delegate requests to list, save or remove radio favourites to the backend. Saved
stations persist on the device; confirm only actual tool results.
